# System Configuration

- Do **NOT** modify the `FreeRTOSConfig.h` file.
- Do **NOT** modify the `nvic.h` file.

System configuration files, such as pin mappings, can go in this folder.

Each board that this code can be tested with should have its own file within the `boards` folder.
You can select which pin mapping to use in the `pin_cfg.h` file.
